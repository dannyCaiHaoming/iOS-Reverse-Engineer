# Week 1 证据日志模板

每一个风险假设一张表。不要把截图、命令或代码片段堆在一起而没有结论。

| 字段 | 内容 |
| --- | --- |
| 编号 | `W01-EV-01` |
| 攻击面与资产 | 例如：UserDefaults 中的登录凭据 |
| 风险假设 | 在指定威胁模型下，凭据可能暴露或被误用 |
| 静态/配置线索 | 文件名、函数名、配置键、代码行或截图说明 |
| 验证环境 | 自建 Lab、模拟器/真机、构建时间、账号状态 |
| 操作步骤 | 任何同学可重复的编号步骤 |
| 运行证据 | 观察到的界面、日志、文件或受控请求；说明证据存放位置 |
| 已证明 | 只写当前证据支持的事实 |
| 未证明/待确认 | 服务端接受性、真实业务影响、权限绑定等未验证内容 |
| 风险判断 | 资产、攻击者能力、利用条件、影响范围和等级依据 |
| 修复建议 | 客户端、服务端或流程责任方；避免“加强校验”类空话 |
| 复测方法 | 修复后应出现的拒绝、脱敏、权限校验或日志结果 |
| 面试讲法 | 60 秒内说明发现、验证、边界和价值 |

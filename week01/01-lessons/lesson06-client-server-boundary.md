# Lesson 06：客户端风险与服务端边界，别把 Hook 结果误判成业务漏洞

## 本课目标

这是第 1 周最重要的“面试分水岭”。

你要学会：

- 客户端风险和业务漏洞的区别。
- 为什么客户端防护不能替代服务端鉴权。
- 如何判断一个客户端问题是否有真实业务影响。
- 面试中如何讲清 Hook、绕过、本地状态篡改的边界。

## 为什么这课非常关键

很多初学移动安全的人会犯一个错误：

> 我把客户端 `isVIP` 改成 true，所以这是高危漏洞。

面试官会继续问：

> 服务端有没有重新校验会员状态？

如果你答不上来，就会显得只会客户端技巧，不懂业务安全。

公司真正关心的是资产影响：

- 是否能越权访问数据。
- 是否能绕过支付。
- 是否能获取会员权益。
- 是否能接管账号。
- 是否能泄露隐私。
- 是否能影响服务端状态。

客户端现象只是第一步。

## 三类移动端风险

### 1. 直接客户端风险

这类风险主要发生在本地或隐私暴露场景，不一定依赖服务端。

例子：

- token 明文写入 UserDefaults。
- 手机号打印到日志。
- 身份证照片缓存到普通目录。
- WebView 注入 token 到 H5。
- 剪贴板保存验证码或 token。

判断方式：

```text
敏感数据是否暴露？
暴露路径是否可行？
暴露后是否能被复用或造成隐私影响？
```

这类风险通常可以较直接定级，但仍要看数据敏感性和可利用条件。

### 2. 客户端绕过型风险

这类风险必须继续验证服务端。

例子：

- Hook `isVIP` 返回 true。
- 修改本地价格。
- 绕过按钮置灰。
- 修改本地权限开关。
- 跳过客户端登录判断。

判断方式：

```text
服务端是否重新校验身份？
服务端是否重新校验权限？
服务端是否重新计算价格？
服务端是否校验订单归属？
服务端是否校验会员状态？
```

如果服务端校验严格，客户端绕过可能只是本地 UI 问题。

如果服务端相信客户端字段，才会变成业务漏洞。

### 3. 入口放大型风险

这类风险本身可能不是漏洞，但能和其他问题组合。

例子：

- URL Scheme 打开任意 WebView URL。
- JSBridge 暴露过多能力。
- ATS 全局放开。
- Debug 日志过多。
- 任意 deeplink 参数进入业务路由。

判断方式：

```text
这个入口是否能接收外部输入？
是否能进入敏感流程？
是否能和 XSS、越权、弱鉴权组合？
```

## 标准判断流程

发现一个客户端问题后，按这个流程走：

```text
1. 识别资产
2. 确认入口
3. 说明信任边界
4. 提出风险假设
5. 在授权环境验证客户端行为
6. 判断是否需要服务端配合
7. 验证服务端是否兜底
8. 定级
9. 给出客户端和服务端修复建议
10. 复测
```

这就是训练营要求的完整闭环。

## 示例 1：UserDefaults token

现象：

```text
access token 明文写入 UserDefaults。
```

资产：

```text
token 是服务端鉴权凭据。
```

风险：

```text
泄露后可能被复用访问用户资源。
```

还要问：

```text
token 有效期多长？
是否绑定设备？
是否支持吊销？
是否有 refresh token？
是否有异常检测？
```

修复：

```text
客户端改用 Keychain。
服务端实现短期 access token、refresh token 保护、吊销和异常检测。
日志和 UI 不展示 token。
```

## 示例 2：Hook isVIP

现象：

```text
通过 Hook 让客户端显示自己是会员。
```

不能立刻定高危，因为：

```text
它可能只改变本地 UI。
```

继续验证：

```text
请求会员资源时，服务端是否重新检查会员状态？
服务端是否根据用户身份查询权益？
客户端是否能传 isVIP 字段影响服务端返回？
```

定级：

- 服务端严格校验：低或信息类。
- 服务端相信客户端字段并下发会员资源：高。

## 示例 3：URL Scheme 打开 WebView

现象：

```text
securitylab://webview?url=https://example.com
```

风险假设：

```text
外部输入可能控制 WebView 加载页面。
```

继续验证：

- 是否允许任意域名。
- 页面能否访问 JSBridge。
- JSBridge 是否有敏感能力。
- 是否注入 token。

定级：

- 只能打开白名单普通页面：低。
- 任意页面 + 敏感 JSBridge + token 注入：高。

## 面试表达模板

当你讲客户端绕过时，用这个模板：

```text
这个实验证明客户端本地判断可以被影响。
但我不会直接把它定为业务漏洞。
我会继续看服务端是否重新做鉴权、授权和状态校验。
如果服务端能兜住，它是客户端防护不足或体验问题。
如果服务端相信客户端字段，才会形成真实业务风险。
修复上，客户端减少暴露面，服务端必须保证最终安全边界。
```

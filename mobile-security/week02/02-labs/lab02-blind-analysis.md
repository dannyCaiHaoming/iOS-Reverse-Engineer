# Lab 02：75 分钟隐藏源码动态分析

这是本周的独立分析考核。开始前关闭 `Sources/` 和 `Tests/` 下所有源码文件，不查看 Lesson 01 中的场景解析段落；可以查看本文件、CLI 输出和 LLDB。

## 目标

在保留 Debug 符号但不读源码的条件下，重新定位：

1. 敏感动作入口。
2. 客户端策略判断。
3. 请求或服务端接收位置。
4. 安全与错误授权的分叉点。
5. 至少一条 5 节点调用链。

## 允许使用

- `swift run BusinessLogicLabCLI <scenario>`
- `lldb .build/debug/BusinessLogicLabCLI`
- `target modules list`
- `image lookup -rn <regex>`
- breakpoint、backtrace、frame variable、expression
- 本地 `05-resources/local-reference.md`

## 禁止使用

- 打开源码、测试或已完成的引导实验答案。
- 搜索网络题解。
- 运行自动生成完整调用图的第三方脚本后直接提交结果。
- 把已记住的函数顺序直接抄成分析结论而不重新取证。

## 时间盒

### 0-10 分钟

运行三个场景，记录行为差分和两个初始假设。

### 10-25 分钟

列模块和候选符号，给候选入口排序。至少保留一个后来被排除的入口。

### 25-50 分钟

在 baseline 建共同调用链，记录调用栈和关键对象。

### 50-65 分钟

对比两个 tamper 场景，找到服务端分叉。

### 65-75 分钟

写已证明、未证明、错误路径和下一步静态分析计划。

## 最小交付

使用 `blind-analysis-log-template.md`，必须包含：

- 时间线；
- 候选入口评分；
- 命令与断点；
- 5 节点调用链；
- 3 组关键变量值；
- 一个错误入口及排除依据；
- 两个场景的风险边界；
- 第 3 周需补足的静态证据。

## 评分重点

- 入口选择与调整：20 分。
- 调用链证据：25 分。
- 数据流证据：20 分。
- 安全边界：20 分。
- 时间和日志质量：15 分。

70 分合格。若调用链或安全边界任一项为 0，直接不合格。

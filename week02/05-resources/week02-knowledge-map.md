# 第 2 周知识地图

## 主干能力

```text
业务资产与状态机
  -> 入口选择
  -> 候选调用图
  -> LLDB 符号发现
  -> 调用栈验证
  -> 关键对象/参数验证
  -> 安全与错误场景差分
  -> 风险边界
  -> 修复与回归测试
```

## A. 业务与安全模型

必须掌握：

- 认证、授权、客户端准入的区别。
- 主体、动作、资源三元组。
- token、role、premium、owner 的生产者、转换者和消费者。
- 客户端缓存、请求声明、服务端权威会话的信任级别。
- UI 绕过、本地敏感能力、服务端越权三种影响层级。

达到深度：能针对一个陌生业务流程画状态机和信任边界，并从中生成断点计划。

## B. 源码辅助逆向

必须掌握：

- 行为、数据、API、控制流、跨层边界五种入口。
- 候选调用图和证据等级 S1/S2/D1/D2。
- Swift closure、protocol、extension、property wrapper、async 对调用关系的影响。
- 代码可达性、值可控性、权威决策和最终影响四步验证。

达到深度：不顺序阅读全部源码，能围绕一个安全问题缩小到高价值函数集合。

## C. LLDB

必须掌握：

- target/process/thread/frame 模型。
- 模块与 Swift 符号正则搜索。
- 符号断点、条件断点、断点命令。
- `bt`、frame 导航、`frame variable`、`expression`、`po`。
- `next`、`step`、`finish`、`continue` 的选择。
- Debug/Release、优化、thunk 和变量不可见问题。

达到深度：能够用可复现命令证明一条 5 节点业务调用链和关键字段传播。

## D. 盲动态分析

必须掌握：

- 先行为差分，再符号侦察，再断点验证。
- 候选入口按资产距离、输入可控性、分支价值、可观察性排序。
- 记录错误入口和排除依据。
- 在时间盒内停止低价值深挖。

达到深度：关闭源码后，75 分钟内重新定位入口、客户端策略和服务端授权分叉。

## E. 风险与公司交付

必须掌握：

- 已证明、未证明、待服务端确认。
- 攻击者能力和风险成立条件。
- 根因写到错误信任源和缺失授权检查。
- 服务端修复、客户端改进、SDL 预防三层建议。
- 合法请求与攻击请求并存的复测矩阵。

达到深度：报告不夸大本地现象，能把真实授权问题转化为研发可执行修复和测试。

## 本周不要求

- 独立恢复无符号 Swift Release 二进制。
- 熟练阅读 ARM64 汇编。
- 绕过真实 App 的代码签名、反调试或证书绑定。
- 使用 Frida。
- 对未授权商业 App 做分析。

这些边界不是降低要求，而是保证 12 小时聚焦调用链与证据方法。第 3-4 周会逐步移除源码和完整符号。

## 与后续课程的接口

- 第 4 周：把自建 Demo 换成首次接触的授权 iOS 样本。
- 第 5-6 周：用 ARM64 与 ObjC Runtime 解释动态现象。
- 第 9 周：把 LLDB 观察点转成 Frida 持续追踪脚本。
- 第 11-12 周：接入真实受控 HTTP/mock backend，验证 Mobile API 边界。
